* **Modeling Tools:** PowerDesigner / Draw.io[cite: 1]
* **Spreadsheet & Analysis:** Microsoft Excel / Google Sheets[cite: 1]
* **E-Learning Portal:** [ELSA INSTIKI](http://elsa.instiki.ac.id)[cite: 1]
* Berikut adalah beberapa rekomendasi platform **MySQL Online / Cloud Database** (baik berupa SQL Fiddle sederhana maupun layanan Cloud DBMS gratis) yang sangat cocok digunakan mahasiswa untuk praktikum tanpa perlu menginstal XAMPP/MySQL lokal:

---

### 1. SQL Fiddle & Online Compiler (Sederhana & Tanpa Registrasi)

Sangat cocok untuk latihan cepat kueri DDL, DML, JOIN, hingga Subquery langsung dari peramban (*browser*).

* **db-fiddle ([db-fiddle.com](https://www.db-fiddle.com?utm_source=gemini))**
* **Kelebihan:** Mendukung MySQL versi terbaru (8.0), tampilan sangat bersih, mendukung pembagian tautan (*share link*) kueri untuk dikumpulkan ke dosen.
* **Penggunaan:** Panel kiri untuk schema/DDL (`CREATE TABLE`, `INSERT`), panel kanan untuk kueri SQL (`SELECT`, `JOIN`, dll).


* **OneCompiler MySQL ([onecompiler.com/mysql](https://onecompiler.com/mysql?utm_source=gemini))**
* **Kelebihan:** Ringan, responsif, dan dapat dijalankan dengan lancar melalui *smartphone* atau tablet.


* **SQL Fiddle ([sqlfiddle.com](https://sqlfiddle.com?utm_source=gemini))**
* **Kelebihan:** Platform klasik yang populer untuk belajar dan menguji struktur skema relasional dasar.



---

### 2. Free Cloud MySQL Database (Database Utuh Terintegrasi)

Sangat cocok untuk pengerjaan proyek akhir (seperti Minggu 14–16), karena memberikan *host*, *username*, *password*, dan *port* agar dapat dihubungkan ke GUI seperti SQLyog, MySQL Workbench, DBeaver, maupun aplikasi *web*.

* **Aiven for MySQL ([aiven.io](https://aiven.io?utm_source=gemini))**
* **Fitur:** Menyediakan paket *Free Tier* untuk 1 node MySQL database.
* **Kelebihan:** Performa sangat stabil, mendukung koneksi SSL, dan ramah untuk pemula.


* **PlanetScale ([planetscale.com](https://planetscale.com?utm_source=gemini))**
* **Fitur:** Database MySQL berbasis *cloud serverless*.
* **Kelebihan:** Sangat populer di industri, mendukung *schema branching* (mirip Git), dan koneksi sangat cepat.


* **Clever Cloud ([clever-cloud.com](https://www.clever-cloud.com?utm_source=gemini))**
* **Fitur:** Layanan *cloud hosting* yang menyediakan *Free Add-on* MySQL (versi MySQL 5.7 / 8.0) dengan kuota penyimpanan hingga 10 MB (cukup untuk latihan praktikum).

### 💡 Rekomendasi Penggunaan untuk Perkuliahan:

1. **Latihan Pertemuan 4–13 (DDL, DML, JOIN, Subquery):** Gunakan **db-fiddle.com** karena praktis dan tidak memerlukan proses registrasi/pendaftaran akun.
2. **Latihan Pertemuan 14–16 (View, Projek Analisis, Tugas Akhir):** Gunakan **Aiven** atau **Clever Cloud** agar data tersimpan secara permanen di *cloud* dan bisa diakses menggunakan GUI SQLyog / DBeaver di komputer masing-masing.
